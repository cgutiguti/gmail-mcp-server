Claude Gmail MCP

Claude Gmail MCP is an open-source, user-run connector that lets Claude access a Gmail mailbox through Google's OAuth flow so the user can ask Claude to search, read, label, draft, send, import, and organize email.

Application name: Claude Gmail MCP

Purpose Of Claude Gmail MCP

Claude Gmail MCP is the application named on the OAuth consent screen. Its purpose is to connect Claude to a Gmail account that the user owns or is authorized to administer.

The app requests Gmail access so Claude can carry out user-directed mailbox tasks, including searching messages, reading threads, applying labels, creating drafts, sending replies, downloading messages or attachments, and importing email archives into Gmail.

This project runs on the user's machine and exposes Gmail tools over the Model Context Protocol. It is intended for personal or internal workflow automation where the user remains in control of OAuth authorization and assistant actions.

User-controlled OAuth

The user authenticates directly with Google and can revoke access from their Google account settings at any time.

Local credential storage

OAuth client files and refresh tokens are stored on the user's computer, typically under ~/.gmail-mcp/.

Scoped Gmail tools

The server filters available MCP tools based on the OAuth scopes granted during authentication.

Google User Data Use

Claude Gmail MCP uses Google user data only to perform the Gmail actions requested by the authenticated user. Message contents, labels, attachments, and metadata are accessed only as needed for those user-directed actions. The maintainers do not operate a hosted service that collects or stores Gmail data.

Privacy Policy

This project is designed to run locally. The maintainers do not collect Gmail messages, contacts, attachments, OAuth tokens, telemetry, or usage analytics through this software.

Data Access

When you authenticate, Google grants the local MCP server access according to the OAuth scopes you approve. Depending on scopes, this may include reading messages, modifying labels, creating drafts, sending email, or managing settings.

Data Storage

The server stores OAuth credentials on your local machine. You should protect these files, avoid committing them to source control, and delete or rotate them if you believe they were exposed.

Data Sharing

The software sends Gmail API requests to Google as needed to satisfy user-requested actions. It does not intentionally transmit mailbox data to the maintainers or third-party analytics services.

Revocation

You can revoke the app's Google access at any time from your Google Account security settings. You can also remove local credentials by deleting the relevant files under ~/.gmail-mcp/.
